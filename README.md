# Long-Term Scenarios

Streamlit application to simulate long-term scenarios for **baseload and PV captured prices** in the Italian electricity market (2026–2040).

The tool lets users modify key market fundamentals — demand, renewable capacity, gas prices — and immediately observe the impact on price trajectories. Built on a constrained Fixed Effects Ridge regression trained on Aurora quarterly releases.

## Requirements

- Python 3.9+
- Dependencies listed in `requirements.txt`

Key libraries: `streamlit`, `pandas`, `numpy`, `cvxpy`, `plotly`

## Installation

```bash
git clone <https://github.com/smoroniEnf/Long_Term_Scenarios>
cd <https://github.com/smoroniEnf/Long_Term_Scenarios>
pip install -r requirements.txt
```

## Run

```bash
streamlit run webapp_version8.py
```

## Input files

The following files must be present in the `csv/` folder:

| File | Description |
|------|-------------|
| `training_data.csv` | Aggregated Aurora releases, used for model training |
| `data_baseline_scenario_3.csv` | Internal reference scenario, used as baseline in the app |
| `capacity_factor_hydro.csv` | Yearly hydro capacity factors (auto-generated by `model.ipynb`) |

Trained models are loaded from `.pkl` files in the root folder (one for baseload, one for PV captured price).

## Model

The model is a constrained Fixed Effects Ridge regression (`model_class.py`) trained in `model.ipynb`. It takes 7 numerical inputs (demand, PV capacity, wind capacity, battery storage, hydro generation, gas price PSV, EUA) plus release and year fixed effects, and predicts baseload and PV captured prices separately.

## App features

- Interactive tabs to edit each input variable year by year (2026–2040)
- CSV upload for custom scenarios
- Scenario simulation with residual correction and 95% confidence intervals
- Per-variable price impact decomposition
- Export results as CSV
